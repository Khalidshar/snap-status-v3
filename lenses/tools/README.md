# أدوات حزمة العدسات

## إعادة التوليد

يتطلب Node.js وPlaywright مع Chromium وخط Readex Pro محليًا.
لا يحتاج Lens Studio أو تسجيل دخول. من جذر المستودع:

```text
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node lenses/tools/render.cjs lenses/content.json /path/to/ReadexPro.woff /tmp/rawwag-pack
```

على ويندوز استخدم مسارات محلية مناسبة، مثل `C:/temp/rawwag-pack`.
إذا كانت الاعتمادات والمتصفح موجودين فلا حاجة لإعادة تثبيتهما.
يمكن تحديد متصفح مثبت عبر متغير البيئة `MADAR_CHROMIUM`، ومسار اعتماد موجود عبر `NODE_PATH`.
الأداة تستخدم Chromium محليًا، تضمّن الخط كبيانات، وتمنع طلبات الشبكة أثناء الرسم.
توقف التنفيذ إذا لم يحمل الخط أو تجاوز النص مساحة البطاقة.
تهرّب علامات HTML في المحتوى لتظل نصًا ولا تتحول إلى وسوم.
النتيجة ٥٩ صورة شفافة: ٤٢ للسؤال والجواب والإرشاد، ١٦ للألقاب والبداية، وأيقونة واحدة.

ولّد إلى مجلد مؤقت أولًا، وافحص العربية والتفاف النص بصريًا قبل نقل الصور إلى `lenses/pack/`.
لا تغيّر نص سؤال أو جواب لحل مشكلة رسم.
وجود كلمة ممنوعة في مصدر البيانات لا يبرّر حذفها خلسة: أداة الفحص تكشفها وتحتاج مراجعة المحتوى.
لا تستورد مجلد الأدوات أو ملف الخط أو الاختبارات إلى مشروع العدسة.

## أيقونة شيهانة المعتمدة — ١٣ نوفمبر

أضيفت `pack/brand/icon-320.png` من الملف الذي جهّزته شيهانة في مشروع Lens Studio.
نسخة `pack/brand/icon.png` مطابقة لها لتوافق مسار الحزمة والمولد والفاحص الحالي.
الملف PNG، مقاسه ٣٢٠×٣٢٠، وحجمه ٤٦٬٨٤٥ بايت.
بصمة SHA-256: `4ab6e8d3a0317c1b1b38a0585e75d5152b387466c652a2bc0936c16cdbda6971`.
المقاس موثّق في [Creating an Icon — Best Practices لدى Snap](https://developers.snap.com/lens-studio/publishing/configuring/creating-an-icon#best-practices).
هذه إضافة ملف جاهز؛ لا تتضمن نشرًا أو تسجيل دخول أو اعتماد بقية تجربة العدستين.

## المقاس والرخصة

- [توثيق Snap الرسمي لأيقونات Lens Studio](https://developers.snap.com/lens-studio/publishing/configuring/creating-an-icon):
  التسليم PNG بمقاس **٣٢٠×٣٢٠**. يضبط المولد والفاحص هذا المقاس. راجع أيضًا قص الدائرة وإطار القالب الرسمي داخل البرنامج.
- [رخصة Readex Pro الأصلية في Google Fonts](https://github.com/google/fonts/blob/main/ofl/readexpro/OFL.txt):
  **SIL Open Font License 1.1**. تسمح باستخدام الخط وتضمينه وإعادة توزيعه مع إشعار الحقوق والرخصة.
  لا يُباع الخط بمفرده، وأسماء الخط المحجوزة لها شروط عند التعديل.
  لم نضف ملف خط إلى هذا التغيير؛ استخدم نسخة Readex Pro مرخّصة محليًا.
  عند إضافته للمستودع لاحقًا أرفق ملف OFL.txt وإشعار الحقوق الأصليين معه.

## الفاحص

```text
python lenses/tools/check.py
python lenses/tools/check.py --root /path/to/lenses
```

Python 3.11 أو أحدث؛ بلا حزم إضافية. رمز الخروج ٠ للنجاح و١ للمخالفة.
يطبع سطر `isTrueAnswers` الجاهز للصق؛ في Inspector عيّن الخيارات المنطقية بالترتيب نفسه.
يتحقق من تسلسل qNN/aNN وعدد ٢٠، وترتيب الإجابات، وألقاب العداد،
وملفات الإرشاد، وتوقيع PNG وبنيته وCRC ومقاساته، وكلمات المحتوى الممنوعة.
يفحص النصوص المعروضة ومصادرها في content.json، لا نصوص التوثيق التي تذكر الممنوعات عمدًا.
ليس OCR ولا فحصًا لرسوم QR أو الشعارات داخل الصور؛ تلك مراجعة بصرية.

ميزانية كل عدسة ≤ ٨×١٠٢٤×١٠٢٤ بايت:
مجلد صورها + كل ملفات brand المشتركة + سكربتها + content.json احتياطيًا.
هذا مجموع ملفات الإدخال، ولا يثبت الحجم النهائي بعد تجميع Lens Studio؛ تفحصه شيهانة هناك.
كل PNG ≤ ٢٠٤٨×٢٠٤٨ بما فيه الملفات الإضافية تحت pack.

تشغيل الاختبارات موثق في `../scripts/README.md`.
تبقى نصوص content.json الأصلية بلا تغيير. أكّدت شيهانة أن السؤال ١٧ نص عن QR وليس رمزًا مرسومًا؛
الفاحص النصي يسجّل الكلمة ولا يثبت وجود رمز في الصورة. ستستبدل شيهانة السؤال احتياطًا،
ولم يُعدّل السؤال أو صوره في هذا التغيير. تبقى ملاحظة الفحص النصي لحين وصول تعديلها.
