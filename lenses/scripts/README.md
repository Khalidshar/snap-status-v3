# ربط سكربتات عدسات «روّق»

السكربتان من Gemini في فرع الأساس؛ المحاكاة لا تعوّض تجربة شيهانة داخل Lens Studio.
أضف كل ملف إلى Asset Browser ثم إلى مكوّن Script على كائن العدسة المناسب.
اسحب المراجع التالية إلى حقول المكوّن في Inspector.
أعطِ كل صورة مادة مستقلة تدعم `mainPass.baseTex` حتى لا تتغير بقية الصور معها.
المسارات أدناه بالنسبة إلى `lenses/pack/`.

## صح أو خطأ — TiltQuiz.js

| المدخل | النوع | مكان الربط والقيمة |
|---|---|---|
| displayImage | Component.Image | مكوّن صورة بطاقة السؤال/الجواب فوق الرأس، يبدأ مفعّلًا |
| badgeImage | Component.Image | مكوّن صورة مستقل لعلامة صحة إجابة اللاعب |
| scoreText | Component.Text | مكوّن نص النتيجة النهائية؛ اربطه لإظهار النتيجة، وإلا تنتهي اللعبة دون نص |
| questionTextures | Asset.Texture[] | عشرون صورة `truefalse/q01.png` إلى `q20.png` بالترتيب العددي |
| answerTextures | Asset.Texture[] | عشرون صورة `truefalse/a01.png` إلى `a20.png` بالترتيب نفسه |
| isTrueAnswers | bool[] | عشرون خيارًا؛ أول عشرة مفعّلة والبقية غير مفعّلة، من سطر أداة الفحص |
| badgeCorrect | Asset.Texture | علامة مستقلة تعني «إجابتك صحيحة» من القالب؛ ليست بطاقة جواب السؤال |
| badgeIncorrect | Asset.Texture | علامة مستقلة تعني «إجابتك خاطئة» من القالب |
| headTracker | SceneObject | كائن تتبع الرأس الفعلي الذي تتغير زاوية دورانه عند ميل الرأس |
| invertTilt | bool | افتراضيًا غير مفعّل؛ جرّبه عند انعكاس اتجاه الميل في الكاميرا |
| tiltAngleThreshold | float | زاوية الإجابة بالدرجات؛ الافتراضي ١٥ |
| neutralAngleThreshold | float | نطاق العودة للوسط بالدرجات؛ الافتراضي ٥ وأقل من زاوية الإجابة |
| resultDuration | float | مدة إظهار بطاقة الإجابة بالثواني؛ الافتراضي ١٫٥ وقيمة موجبة |

`hint-right.png` و`hint-left.png` صورتا إرشاد ثابتتان يمين الرأس ويساره، وليستا مدخلين للسكربت.
لا توجد علامتا badge مستقلتان ضمن الحزمة؛ استخدم علامتي القالب وراجعهما بصريًا.
بطاقة `aNN` توضح حقيقة السؤال، بينما badge يوضح صحة اختيار اللاعب؛ يمكن أن يختلفا.

الترتيب المطلوب للمصفوفات ثابت قبل التشغيل؛ السكربت يخلط فهارسها معًا.
بعد الإجابة يمنع إجابة ثانية خلال ظهور النتيجة، ثم ينتظر عودة الرأس للوسط قبل السؤال التالي.
عند السؤال الأخير يخفي الصورة ويعرض «نتيجتك: … من 20». لا يوجد زر إعادة جولة في هذا السكربت.

## عداد الثقافة — RandomSpinner.js

| المدخل | النوع | مكان الربط والقيمة |
|---|---|---|
| displayImage | Component.Image | مكوّن صورة اللقب فوق الرأس بمادة مستقلة |
| coverTexture | Asset.Texture | صورة البداية `meter/spinner.png`؛ اختيارية |
| titleTextures | Asset.Texture[] | `meter/title01.png` إلى `title15.png`؛ لا تترك المصفوفة فارغة |
| spinDuration | float | مدة الدوران بالثواني؛ الافتراضي ٣ وقيمة موجبة |
| spinSpeed | float | الفاصل الزمني بين البطاقات بالثواني؛ الافتراضي ٠٫٠٥ وقيمة موجبة |

النقر يبدأ الدوران؛ النقرات أثناءه لا تعيد تشغيل المؤقت.
النتيجة لقب عشوائي للترفيه ولا تمثل قياسًا فعليًا للثقافة.
**خطأ مثبت في الأساس:** منع التكرار يقارن بآخر بطاقة في الدوران، وليس نتيجة الجولة السابقة.
لم يُغيّر كود Gemini؛ يثبت الاختبار المشكلة لتراجعها شيهانة ويصححها Gemini.
عند ترك الألقاب فارغة يبقى الدوران عالقًا بسبب العودة المبكرة؛ الربط أعلاه يتجنب ذلك.

## الفحص المحلي

من جذر المستودع:

```text
python lenses/tools/check.py
python -m unittest discover -s tests -p test_lenses_pack.py -v
node --test lenses/tools/logic.test.cjs
```

ملف الاختبار متوافق كذلك مع `pytest tests/test_lenses_pack.py`.
الفحوص لا تتطلب حسابًا ولا Lens Studio، ولا تعدّل المحتوى.
اختبار جاهزية الحزمة واختبار تكرار اللقب يفشلان عند وجود العيوب المذكورة، دون استثناء يخفيها.
راجع `../tools/README.md` لإعادة توليد الصور ومصادر المقاسات والرخصة.

لا يوجد تسليم في `lenses/incoming/` في نسخة الأساس. أي تسليم لاحق لا يطبّق تلقائيًا:
يجب أن تصرّح شيهانة بمراجعته أولًا، ثم يراجع فرق التعديل ويختبر على الفرع نفسه.
