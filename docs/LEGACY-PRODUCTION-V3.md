# آلية القديم داخل «روّق مع خالد»

فرع من main يتضمن shehana/stop-v3 وقراري ٢ و٣ نوفمبر. الجديد يبقى موقوفاً، ولا يبدأه هذا التغيير. راجع `OLD-BOTS-PRODUCTION.md` للمقارنة مع المصدر.

## المسار

`MADAR_LEGACY_PRODUCTION=1` يبدّل مصدر المحتوى في التطبيقين إلى مصانع القديم. المفتاح مطفأ افتراضياً. يبقى الحجز وسجل الوكلاء والفحص والتبنّي والموافقة وسياج الإرسال في التطبيقين. مصدر `legacy_production` يربط المشاهد والأصول وبصماتها والتوقيت بسياسة الصوت وبصمة المحتوى؛ ولا يقبل المخرج أصولاً من الشبكة.

- الأخبار: ٢–٤ أخبار، والعاجل ثلاثة؛ ١٢ ثانية تقريباً للخبر، والبداية بالعنوان والصورة دون افتتاحية فارغة. صورة RSS ثم og:image ثم اكتشاف صورة مطابقة للعنوان في Google News، مع مصدر الصورة والعنوان والتفصيل ووقت النشر واسم المصدر. ترفض القصة بلا صورة. Google News دليل اكتشاف، وليس صفحة مقال.
- التقنية والأناقة: يقرأ HTML المقال كاملاً، ويأخذ النقاط وصورها من عناوينه وفقراته، وهو مسار `plain_points` المجاني في القديم. لا يستدعي Gemini أو NIM. المصادر الإنجليزية المعتمدة تُترجم عبر بوابة الجلب المجانية؛ تُحفظ استجابة الترجمة وربطها بكل حقل أصلي، وتُرفض استجابة تغيّر الأرقام أو النص المصدر المعاد. تتقدم الماركات العشر المحددة في سجل الأخبار، دون منع بقية عروض الأزياء وإطلالات المشهورات. لا تُضاف مصادر غير معتمدة.
- القرآن: نص مجمع الملك فهد المثبت دون تغيير، والتفسير الميسر الحرفي من quranenc. قائمة القديم ذات ٣١ قارئاً: MP3Quran وتوقيت الآية، ثم EveryAyah، ثم مؤسسة القرآن عند تهيئة بوابتها وتفعيل `MADAR_QURAN_AUDIO`. لا تُقرأ مفاتيح المؤسسة خارج بوابتها، وتدخل قراءاتها المتاحة وفق سياسة حفص. ينزّل السورة قبل قصها محلياً؛ لا يمرر عنوان HTTP إلى FFmpeg. تُعرض الآيات بخط أميري قرآن المثبت ببصمته ورخصته، مع فحص تغطيته لحروف النص الرسمي بدون تغيير النص.
- الأذكار: تسجيل بشري من قائمة القديم، والقص بين وقفات في التسجيل، والأعمدة من RMS التسجيل نفسه.
- هل تعلم/المواقف: أربع بطاقات. اللغز: ثلاثة، لكل منها خمس ثوانٍ وعدّ تنازلي وتكات ثم جواب بصوت Edge المجاني. قراءة الحديث تستخدم الصوت المجاني نفسه كما في القديم؛ هذا الطرف يرفض القرآن والأذكار والأدعية وأي نص خارج الحديث والأجوبة المثبتة.
- الموسيقى: True Patriot، مع نسبتها ورخصة CC BY-SA 3.0 في بيانات الأصول. لا موسيقى أو مؤثرات مع القرآن أو الأذكار أو الحديث أو مشاهد الليل الدينية.

## التجربة اليدوية دون إرسال

متطلبات Linux: FFmpeg وffprobe وfontconfig وlibseccomp، وNode. من بيئة المستودع:

```sh
uv sync --all-packages
npm ci --ignore-scripts
npx playwright install --with-deps chromium
uv venv /opt/madar/legacy-voice
uv pip sync --require-hashes --python /opt/madar/legacy-voice/bin/python config/production/voice-requirements.txt
uv run python scripts/generate_legacy_previews.py --output /var/tmp/rawwag-owner-previews
```

بيئة الصوت منفصلة عن بيئة المخرج، واعتمادياتها مثبتة بالبصمات. لا تُضاف حزم خارجية لبيئة Python الأساسية في الإصدار.

الأمر يجهز عينات جميع أوامر المحتوى الثلاثة والعشرين للبوتين افتراضياً (٤٦ مقطعاً). ينتج أسماء عربية واضحة مثل `snap-عاجل.mp4` و`status-عاجل.mp4`، وملف وصف للمصادر والصور والصوت لكل عينة، وجدول `quality-matrix.md`. `--commands` يحدد أوامر بعينها، و`--app snap|status` يحدد بوتاً. ينشئ بوابة جلب محلية خاصة لهذه العملية ويغلقها في النهاية، ولا يشغّل بوتاً أو خدمة systemd أو مؤقتاً. لا يوجد خيار إرسال في الأداة. يجب أن يكون مجلد المخرجات جديداً.

المخرج طفل مستقل يمنع نداءات إنشاء IP sockets بفِلتر Linux موروث إلى Chromium وFFmpeg، ويتحقق من المنع فعلياً. صفحة Chromium لا تفتح أي عنوان، وتقرأ الصور والخطوط المحلية فقط. الأصول تمر ببصماتها قبل الاستعمال. كل مشهد يرسم في Chromium، ثم يُركّب داخل نافذة الإطار المعتمد.

الفحوص: H.264/AAC و1080×1920 و30 إطاراً/ث، ٣٢–٥٨ث، ≤16MB، قياس LUFS والذروة، سرعة القراءة، حدود النص، الصورة ومصدرها، اليوزر وبطاقة المتابعة. يحتفظ بست لقطات للمقيّم وقائمة التحقق المجانية، ويعيد البناء كاملاً مرة واحدة عند الفشل. يحتوي `report.json` على نجاح/فشل كل أمر وسببه وبصمات الفيديوهات، وفي مجلد كل فيديو لقطاته الست.

## التثبيت

`install_owner_commands.py` يدرج `madar-v3-production-egress@.service` دون تشغيل أو تمكين أو جدولة. مفاتيح الإنتاج الافتراضية صفر. تشغيل البوتين الجديدين يحتاج قرار خالد بعد مشاهدة العينات؛ تثبيت الملفات لا يغيّر قرار الإيقاف. لا يعدّل العمل status-bot القديم أو snap-bot القديم أو /opt/studio-v2.


## استكمال مراجعة ٣ نوفمبر

- أُعيد ترتيب أخبار الظهر وليلة طيبة داخل قسميهما، ثم ترقيم القائمة ١..ن؛ مصادر الأوامر تعتمد المفاتيح لا الأرقام القديمة.
- في الإنتاج الجديد يمر كل أمر مباشرة بمصنعه في البوتين. عند إطفاء مفتاح الإنتاج تُستخدم آية معتمدة لمسار ليلة طيبة القديم، دون تجاوز قفل النص.
- تعمل أدوار الإشراف الستة بعقود مسجلة في `agent_runs` عند تحضير المصدر في التطبيقين، بالإضافة إلى المراحل الاثنتي عشرة القائمة. لا يغيّر الكاتب أو المصلح النص الديني؛ إعادة الإخراج البصرية محدودة بمحاولة واحدة.
- ليالي قبل النوم مرقمة بحسب تاريخ الرياض منذ ٢٦ سبتمبر ٢٠٢٦، ويُثبت رقم الليلة وتاريخها داخل العقد. يثبت نص الحديث الصحيح ودرجته ومصدره قبل الرسم. لا مطر مولّد أو مؤثرات تحت الحديث، التزاماً بقرار منع المؤثرات في الديني.
- يُختبر تناوب هوية القارئ البشرية حتى عند اختلاف معرفه بين المصدرين، وتُنظف أصول المؤسسة ونسخها المسجلة خلال سبعة أيام مع إبقاء سجل التناوب والتدقيق.
- أُصلح موضع طفرة حجز المحتوى بدلاً من حذف الطفرة أو إضعاف اختبارها. اختبار مقاطع الأخبار يحتفظ بعنوان المصدر وعقده كما هما، ويستخدم ساعة ثابتة لضبط اختبار الحداثة.

العينات الحقيقية مهمة شيهانة على جهاز خالد، وليست ضمن تشغيل بيئة التطوير. تحويل الطلب إلى مراجعة بعد نجاح فحوص الكود لا يجيز الدمج أو تشغيل الجديد؛ تبقى مشاهدة خالد للعينات شرطاً للاعتماد.
