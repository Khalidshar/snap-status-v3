# تقسيم التحضير — المهمة ٨

لم تتغير خوارزمية اختيار المحتوى أو النصوص أو إعدادات الصوت أو التخزين. تبقى واجهة `studio_core.production.prepare.Factory` والدالة `prepare` وأسماء الأدوات المستخدمة في الاختبارات متاحة كما هي.

| الملف | المسؤولية |
|---|---|
| `prepare.py` | تجميع الخطة والتحقق منها وحفظها، وواجهة الاستدعاء الحالية |
| `prepare_base.py` | وسيط المصادر، حفظ الأصول، سجل الاستخدام، الصورة، والترجمة والصوت المشترك |
| `prepare_news.py` | الأخبار والمقالات والصور والترتيب ومواقع الأناقة |
| `prepare_religious.py` | القرآن والحديث والأذكار والتفسير والتلاوات البشرية |
| `prepare_variety.py` | المنوعات وحدث اليوم والموجز الحالي |

تستعمل الأجزاء كائن المصنع نفسه وسجل SQLite نفسه والأصول نفسها؛ لم تُنشأ حالة أو طوابير جديدة. بقي إنشاء عميل الشبكة قابلًا للاستبدال عبر `prepare.NetworkClient` كي تعمل الاختبارات القديمة كما هي. لا تغيير في وسيط الشبكة أو عزل الرسم.

فُحصت أشجار الصياغة للطرائق الثلاثين: بقيت الأجسام والتواقيع مطابقة بعد احتساب إعادة تسمية استدعاء عميل الشبكة إلى دالة تمرير الاعتماد. الاختبارات القائمة تُشغَّل دون تعديل، وليس بإعادة كتابة توقعاتها لتلائم التقسيم.

طلبات الأخبار والمصادر ووجهة النشر السابقة مستقلة؛ عند وصولها إلى main تُراجع نقاطها المنقولة في الأجزاء الجديدة قبل دمج هذا الطلب. لا يتجاوز هذا التقسيم تلك التغييرات ولا يعيد سلوكًا أقدم.

## كيف يُتحقق منه على الجهاز

تشغّل شيهانة الاختبارات الحالية للتحضير والتلاوة وسناب وواتساب بعد الدمج، ثم تقارن عينات من الأخبار والمحتوى الديني والمنوعات في البوتين مع النسخة السابقة، بالمدخلات نفسها. تتأكد من ثبات النص الديني والمصادر والصوت والمدة، ومن ظهور فشل المصدر نفسه عند تعذره. لا يحتاج التقسيم مفاتيح أو ترحيل بيانات أو مؤقتات جديدة. النشر والتجربة الحية عند شيهانة.

## ١١ نوفمبر — تقسيم التحضير دون تغيير السلوك (مهمة كوديكس ٨)
- يُفصل التحضير إلى أخبار وديني ومنوعات، مع أساس مشترك وواجهة المصنع القديمة. البوتان يستعملان الكائن والسجلات والأصول نفسها.
- لا تغيير في النصوص أو خوارزمية الإنتاج أو الصوت أو الجدولة. الاختبارات القائمة تبقى كما هي؛ تفاصيل التقسيم والتحقق في `PREPARE-SPLIT-20261111.md`.
