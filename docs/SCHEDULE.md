# الجدولة — نفس البوت القديم

قرار خالد ٩ نوفمبر ٢٠٢٦، وتشغيلها ٢١ نوفمبر («احتاج الجدوله نفس البوت السابق»). الجداول في
`packages/studio-core/studio_core/jobs/schedule.py` منقولة من البوتين القديمين. كل مقطع يمر بنفس فحوص
«أنتج» و«اعتماد» في اللوحة ويصل خالد، وهو ينشر.

- **سناب:** ٦:٤٥ أذكار الصباح، ٧:٣٠ حديث، ٨:٠٠ آية اليوم، ٩ هل تعلم، ١٠ تقنية، ١٢ أناقة، ١ طرائف، ٢ لغز،
  ٤ تقنية، ٥ هل تعلم، ٦ أناقة، ٧ طرائف، ٨ تقنية، ٩ أناقة، ١٠ قبل النوم. ورادار العاجل حتى ٦ يوميًا (٦ ص–١٢ ل).
- **واتساب:** بعد الأذان بـ١٥ دقيقة: الفجر أذكار الصباح (الجمعة: رسالة الجمعة)، الظهر دعاء، العصر أذكار المساء،
  المغرب آية (الأحد والأربعاء: تذكير الصيام، الخميس: الكهف)، العشاء ليلة طيبة. وثابت: ٧:٠٠ حديث، ٧:٣٠ يومك في
  دقيقة، ١:٣٠ أخبار الظهر، ٩:٠٠ م موجز الأخبار، ١٠:٠٠ م قبل النوم. أوقات الصلاة محسوبة بطريقة أم القرى للرياض.
- **أوامر البوت:** «إيقاف الجدولة» و«تشغيل الجدولة» و«مواعيد الجدولة» لكل بوت. «إيقاف كامل» يوقف كل شي.

## التفعيل
```bash
cp /opt/madar/current/config/systemd/madar-v3-schedule.* /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now madar-v3-schedule.timer
```

## الإيقاف
```bash
systemctl disable --now madar-v3-schedule.timer
```
