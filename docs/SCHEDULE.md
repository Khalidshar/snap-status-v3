# الجدولة اليومية — خطة الـ٣٠٠٠ دولار

قرار خالد ٢١ نوفمبر ٢٠٢٦ («إيه، برمجه»)، يحل محل جدول البوت القديم. الجدول في
`packages/studio-core/studio_core/jobs/schedule.py`. كل مقطع ينصنع قبل موعد نشره بنص ساعة، ويمر بنفس
فحوص «أنتج» و«اعتماد» في اللوحة، ويصل خالد وهو ينشر.

**سناب (٩ يوميًا + العاجل حتى ٣):**
٦:٤٥ ص أذكار الصباح (قصص) · ٧:٣٠ ص أخبار السعودية (قصص) · ١:٠٠ م أخبار الظهر (قصص) · ٥:٣٠ م هل تعلم (أضواء) ·
٨:٠٠ م العالم/الرياضة بالتناوب (قصص) · ٩:٠٠ م لغز/طرائف (أضواء) · ١٠:٠٠ م قبل النوم (قصص) ·
١٠:٣٠ م أناقة/تقنية (أضواء) · ١١:٣٠ م طرائف/لغز (أضواء). الأخبار لا تنزل الأضواء أبدًا.

**واتساب (٥ يوميًا، هدفه متابعين لسناب):** بعد الأذان بربع ساعة: الفجر أذكار الصباح (الجمعة: رسالة الجمعة)،
الظهر دعاء، المغرب آية (الأحد والأربعاء: صيام، الخميس: الكهف)؛ و٩ م موجز الأخبار، و١٠ م قبل النوم.

**شرط واتساب:** البوت ما يقدر يرسل إلا خلال ٢٤ ساعة من آخر رسالة من خالد للبوت. بدون رسالة يومية تفشل
مقاطع واتساب المجدولة بـ`WA_SERVICE_WINDOW_CLOSED` (المشرف يبلّغ). سناب ما عليه هذا الشرط.

**أوامر البوت:** «إيقاف الجدولة» و«تشغيل الجدولة» و«مواعيد الجدولة» لكل بوت. «إيقاف كامل» يوقف كل شي.

## التفعيل
```bash
cp /opt/madar/current/config/systemd/madar-v3-schedule.* /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now madar-v3-schedule.timer
```

## الإيقاف
```bash
systemctl disable --now madar-v3-schedule.timer
```
