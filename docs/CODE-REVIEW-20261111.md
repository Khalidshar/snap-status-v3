## ٤. الوكلاء: الوضع والترتيب المقترح

الوضع: ثلاثة أنظمة وكلاء بأسماء متداخلة:
- **أ.** سلسلة الـ١٨ القديمة في سناب (`agent_contract_map`, `n1_*`) لمسار «هل تعلم» فقط، وجزء منها غير مربوط.
- **ب.** مسار الإنتاج المشترك `studio_core/production` (كل الأوامر في البوتين): تحضير ← ستة أدوار إشراف ← المصمم ← الإخراج ← المراجع والمصلّح ← الحكم.
- **ج.** سلسلة واتساب الخاصة (`status_bot/agents.py`) لبطاقة الطقس.

المقترح: مسار واحد من سبع محطات في `studio_core`، والبوتان لا يملكان إلا الإرسال:

| المحطة | الوكلاء | العمل |
|---|---|---|
| ١ المصدر | fact_source، manager | جلب الخبر وإثبات مصدره |
| ٢ الذاكرة | memory، rotation | منع التكرار والتدوير |
| ٣ النص | writer، arabic، proofreading، translation | الصياغة والتدقيق (النص الديني لا يُمس) |
| ٤ التصميم | design | الشكل والخلفية والخط |
| ٥ الصوت والإخراج | voice، renderer | الصوت والفيديو |
| ٦ الفحص | reviewer، fixer، media_verification، judge، quality | مراجعة وإصلاح مرة واحدة ثم حكم |
| ٧ التسليم | final، ثم analyst و content_repair بعده | إرسال، إحصاءات، صيانة |

كل محطة تسجّل نتيجتها في سجل واحد تقرؤه اللوحة وقائمة «أدوات الوكلاء»، فيظهر لكل مقطع أين توقف ولماذا.
