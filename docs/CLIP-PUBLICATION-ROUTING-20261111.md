

## ١١ نوفمبر — وسم وجهة النشر (مهمة كوديكس ٧)
- المقطع السياسي أو العسكري للقصص العامة، وغير السياسي للأضواء. يكفي وجود مشهد سياسي واحد لتوجيه النشرة كاملة إلى القصص العامة.
- التصنيف مشترك للبوتين، ويُكتب في رسالة المقطع واللوحة. بيانات الوجهة تحت بصمة المحتوى، وتُراجع مقابل المشاهد قبل التسليم؛ النتائج القديمة تُقرأ بالتوافق دون تعديل نصوصها.
- التصنيف حتمي محافظ بمصطلحات السياسة والعسكر؛ ليس ضمانًا لفهم السياق أو لأهلية سناب. خالد صاحب قرار النشر النهائي. المحتوى الديني لا يُعاد تصنيفه بتحليل ألفاظ النص الشريف ولا يتغير حرفًا.
- لا نشر تلقائي ولا مؤقتات أو تعديل للنص الديني أو المصادر.
