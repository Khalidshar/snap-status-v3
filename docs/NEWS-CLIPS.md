# مقاطع الأخبار عند الطلب

الأوامر الثمانية تستخدم collect وvalidate دون تعديل، ونفس ملف news-history.sqlite3 الخاص بكل بوت. عنوان الخبر لا يُترجم ولا يُعاد صياغته، ولا تُحمّل صور المقالات. لا يوجد صوت مضاف. الرد الناجح فيديو فقط؛ عدم وجود خبر حديث ينتج رسالة واضحة. الطلب أو الإرسال غير المؤكد يظل محجوزاً ولا يُعاد تلقائياً.

المستمع يجلب الخبر عبر NetworkClient ثم يكتب لقطة ثابتة في news-clips/<event hash>. وحدة madar-v3-snap-news-clip@ تعمل عند الطلب فقط، بلا أسرار وبـ AF_UNIX وPrivateNetwork، وتقيس كل سطر قبل FFmpeg. تُحفظ المدخلات والفيديو والمعاينة ونتيجة الفحص، دون حذف تلقائي. المستمع يتحقق من البصمات وتاريخ الصلاحية و«أوقف» قبل إرسال الفيديو، ولا يسجل ACK إلا بعد قبول تيليجرام للرسالة في محادثة المالك المثبتة.

للمراجِعة عند النشر: scripts/install_owner_commands.py يعرض خطة إضافة وحدة التصيير، و--apply يثبت الملفات فقط ولا يشغل أو يمكّن خدمة أو مؤقتاً. تحتاج الوحدة إلى إعادة تحميل وحدات systemd بواسطة مسؤولة النشر قبل تجربة أمر الأخبار. لا يُشغَّل المثبّت ضمن الاختبارات أو طلب الدمج.
