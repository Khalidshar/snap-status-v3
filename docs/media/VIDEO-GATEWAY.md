# بوابة فيديو الخلفية — قرار ١ نوفمبر ٢٠٢٦

ترتيب الجلب: Pexels ثم Pixabay ثم Coverr. لا اشتراكات ولا توليد مدفوع ولا جدولة.
بوابة Unix مستقلة، لا توسّع قائمة مواقع بوابة الأخبار. الحد ٥٠ ميبيبايت للفيديو
و٢ ميبيبايت لبيانات البحث، مهلة ١٢٠ ثانية، طلبان متزامنان. ترفض التحويلات
والمواقع خارج القائمة والعناوين الخاصة، وتثبّت عنوان الاتصال مع تحقق TLS.

تشغّل يدويًا، من مدير خدمات يحمّل `/etc/madar/media.env` إلى بيئة عملية البوابة فقط:
`python -m studio_core.network.video --socket /run/madar/snap-video.sock`
أسماء الإعدادات: `PEXELS_API_KEY`, `PIXABAY_API_KEY`, `COVERR_API_KEY`.
لا تُقرأ القيم في جلسة التطوير ولا تُنسخ إلى العامل أو الرندر. لا تشغيل على السيرفر ضمن هذا الطلب.
الأسماء تحتاج مطابقة المشغّل مع أسماء متغيرات الملف دون عرض قيمها.
لكل تطبيق عملية ومقبس ومجلد مستقل؛ المستخدمون غير المصرح لهم لا يملكون صلاحية المقبس.

يستدعي العامل `prefetch(query, job_media_directory, socket)` قبل طلب الرندر.
الناتج `background.json` مع الملف والبصمة والمصدر والترخيص واسم صاحب المادة.
لا تُحفظ معاملات الروابط الموقعة. يجب نقل بيانات الإسناد إلى وصف التسليم.
تُنشأ الملفات حصريًا دون استبدال أدلة سابقة، ويُتحقق من البصمة بـ `verify` قبل الاستعمال.
فحص ترويسة MP4 أولي؛ بوابة Media/ffprobe القائمة مطالبة بالتحقق من الدقة والمدة
وسلامة فك الترميز قبل الرندر. امتلاك البصمة لا يثبت سلامة الفيديو أو صلاحية الترخيص.

## حدود الربط

الطلب #71 غير مدموج وقت البناء. لم يُعدّل `render.py` ولا `footage.py`.
هذه واجهة جلب مستقلة؛ لا يُدّعى أن مسار الإنتاج يستدعيها بعد. بعد دمج #71،
يُربط الناتج بعقد footage مع إعادة تحقق البصمة وإبقاء حاوية الرندر بلا شبكة.
فشل المزودين جميعًا يرفع خطأ آمنًا، وتقرر الطبقة الأعلى استخدام الخلفية المحلية.

## مراجع العقود

- https://www.pexels.com/api/documentation/ — Authorization، مسار v1/videos/search.
- https://pixabay.com/api/docs/ — /api/videos/، مفتاح في الاستعلام داخل البوابة فقط.
- https://api.coverr.co/docs/auth — Authorization: Bearer.
- https://api.coverr.co/docs/videos/ — hits وurls.mp4؛ عقود API القديمة الموثقة.
- https://coverr.co/license — يلزم الالتزام بالإسناد وشروط API عند التسليم.

لا اختبار حي بالمفاتيح في هذا الطلب؛ الاختبارات ببدائل محلية فقط.
