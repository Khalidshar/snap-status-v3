# جمع الأخبار الحية ومعاينة الفيديو — ٣٠ أكتوبر ٢٠٢٦

قرار المالك الأحدث: فيديو الخبر الأصلي بصوته عند إتاحته والسماح باستخدامه، وإلا
عنوانه أو المقتطف المسموح كما ورد في بطاقة صامتة. لا تعليق بشري مضاف ولا صوت
مولّد. راجع قرار ٣٠ أكتوبر في `DECISIONS.md`. استخراج فيديو المصدر لم يُربط بعد.

## النتيجة الفعلية

أصبح للتطبيقين مسار تشغيل يدوي يجمع خبرًا عربيًا من الخلاصات المسجلة، ويصنع منه
معاينة فيديو حقيقية. أمر الجمع منفصل عن أمر الرندر؛ الثاني لا يملك شبكة.
**هذه معاينة مراجعة صامتة، وليست مسار إرسال أو تفعيلًا لأزرار تيليجرام وواتساب.**

الأوامر المدعومة بأسمائها وأرقامها الحالية: خبر عاجل، أخبار السعودية، أخبار العالم،
موجز الأخبار، كرة القدم، الأسواق والاقتصاد، التقنية، الأناقة والجمال.

المصادر المستبعدة، والمواقع التي لم تثبت كخلاصات، والمصادر الإنجليزية لا تُجلب في
هذا المسار. تُجلب الخلاصات العربية المرشحة للمراجعة الخاصة فقط؛ لا يتحول نجاحها
إلى إذن نشر. لذلك قد يرفض أمر الأناقة عند عدم توفر خبر عربي مناسب بدل إظهار نصيحة
ثابتة بوصفها خبرًا حديثًا. لم تُثبت ترجمة أو نموذج صوت ولم يُغيّر أي نص ديني.

## اختيار الخبر

- اختيار أحدث عنوان عربي مناسب، لا قص العنوان أو إعادة صياغته. يرفض العناوين فوق ١٨٠ حرفًا، وHTML ومحارف التحكم واللاتينية الطويلة.
- تصنيف حسب الأمر؛ كرة القدم تستبعد كرة السلة واليد والطائرة والتنس والجولف والفورمولا. وصف «هجوم الهلال» أو «مسيرة طلابية» وحده لا يُصنّف هجومًا أمنيًا عاجلًا.
- العاجل: آخر ساعة؛ الأخبار والسعودية والعالم والكرة والاقتصاد: آخر ٢٤ ساعة؛ التقنية: ٧٢ ساعة؛ الأناقة: ٧ أيام. تُرفض التواريخ المستقبلية.
- رابط المقال يجب أن يعود إلى الناشر الصحيح عبر HTTPS دون بيانات دخول؛ قائمة BBC تستوعب مضيف المقال المختلف عن مضيف RSS. تزال معاملات التتبع من الرابط المحفوظ.
- المصدر والرابط والتاريخ وبصمة العنوان محفوظة في حزمة المحتوى. العرض: اليوم – التاريخ – الشهر – السنة – الساعة، بأرقام عربية ونظام ١٢ ساعة وبحساب الرياض، دون اسم المنطقة الزمنية على البطاقة.
- المعاينة تنتهي خلال نصف ساعة أو عند انتهاء نافذة حداثة الخبر، أيهما أسبق. تُعاد مطابقة المصدر والتصنيف والبصمة والحداثة قبل الرندر وبعده، دون إعادة جلب الشبكة.
- يدعم جامع الأخبار مجموعة `seen` لبصمات ما نُشر سابقًا، ولا يغيّرها أثناء الجمع أو المعاينة. لم يُربط بعد بسجل تسليم الإنتاج؛ لا يعدّ العرض نشرًا.
- كل مصدر له محاولة واحدة؛ الفشل منقح ولا يفعّل إعادة إرسال أو بديلًا من الكتالوج الثابت.

## التشغيل في بيئة التطوير أو المراجعة

يلزم وكيل Network Core يعمل مسبقًا بإعداد التطبيق الصحيح والمضيفين المسموحين.
هذه الأوامر لا تنشئ خدمة أو توسّع صلاحيات الشبكة تلقائيًا:

```sh
uv run --frozen snap-bot news-collect --command 'التقنية' --network-config /path/to/snap-network.toml --output /tmp/snap-news-input
uv run --frozen python -m studio_core.renderer.offline --module snap_bot news-render --input /tmp/snap-news-input/content.json --output /tmp/snap-news-render

uv run --frozen status-bot news-collect --command 'أخبار السعودية' --network-config /path/to/status-network.toml --output /tmp/status-news-input
uv run --frozen python -m studio_core.renderer.offline --module status_bot news-render --input /tmp/status-news-input/content.json --output /tmp/status-news-render
```

المجلدات يجب أن تكون جديدة؛ لا يستبدل الرندر ناتجًا سابقًا. تبقى مخرجات المحاولة
الفاشلة للمراجعة، ولا تُحذف آليًا. لا يُقبل ملف تطبيق السناب في رندر الحالات أو العكس.

المشغّل `renderer.offline` يستخدم `libseccomp` الموجودة على Linux لمنع إنشاء مقابس
الشبكة في العملية التابعة وFFmpeg. لا يكتسب صلاحيات، ولا يغيّر حماية النظام المضيف.
يرفض التشغيل إن تعذر فرض العزل. يتطلب الرندر نسخة FFmpeg المثبتة في إعداد التطبيق.

## الفيديو وفصل المسؤوليات

- التخطيط يبقى داخل كل تطبيق في `news_preview.py`؛ النواة تحتوي أداة رسم بطاقات عامة فقط.
- ١٠٨٠×١٩٢٠، ٢٤ إطارًا، ٨ ثوانٍ، H.264. خط المهند والهوية المعتمدة «روّق مع خالد»، مع مطابقة بصمتي الخط والإطار.
- المصدر وتاريخ النشر وعلامة «معاينة للمراجعة» ظاهرة. لا تُستخدم صور من الناشرين.
- الرندر صامت عمدًا، ويوسم `SILENT_REVIEW_ONLY` و`eligible_for_delivery=false`. لا يُشترط تعليق صوتي للأخبار؛ تبقى المراجعة اللغوية والمصدرية مطلوبة قبل أي مسار نشر.
- ملفات الحزمة الجديدة لا تُسجل في سجل إرسال Snap أو Outbox الحالات، ولا تصدر موافقة HUMAN_FRAME.

## الاختبار والقيود

اختُبر الرندر الحقيقي في التطبيقين باستخدام عينات XML اصطناعية واضحة داخل الاختبارات،
مع عزل شبكة فعلي يرثه FFmpeg. فُحصت الصورة الناتجة بصريًا. هذا يثبت خط جمع العينة
المحقونة إلى الفيديو، ولا يثبت قبول خبر حي أو وصول شبكة السيرفر.

نجحت ١٤١ حالة مستهدفة، تشمل اختبارات سجل المصادر ومحلل الأناقة وواجهتي التطبيقين
واستقبال أوامر السناب القائم وحدود الاستيراد. فحص الأنواع الصارم ناجح على ١٢٤ ملفًا.
الفحص الكامل لدفعة سجل المصادر السابقة نجح على GitHub عند الرأس `fe28ed7`؛
فحص هذه الدفعة الجديدة مستقل عنه، ولا يُعد ناجحًا قبل انتهائه.

محاولة الجلب الحي عبر Network Core في بيئة الجلسة توقفت قبل الجلب عند
`PermissionError` لإنشاء مقبس Unix. لم يُستخدم مسار شبكة بديل داخل التطبيق لتجاوز
ذلك. تبقى نتائج فحص الخلاصات العام السابقة في الملف المرفق بالمسودة مستقلة عن هذا الاختبار.

المتبقي قبل الإنتاج: معالج استقبال أوامر البوتين ووحداته المنشورة، ومراجعة الاستخدام
وربط بصمات منع التكرار بسجل نجاح التسليم، واختبار الخبر الحي عبر وكيل
السيرفر. أمر «يومك في دقيقة» المركب لم يُختزل إلى خبر واحد ولا يزال خارج هذا المسار.
