## التنظيم

- المرجع الوحيد لربط الأوامر: `packages/studio-core/studio_core/sources/catalog.json`.
- ٩٢ سجلًا: خلاصات، مواقع مرشحة، كتالوجات موجودة وإسناداتها، مراجع دينية وصوت بشري، ومصدرا الطقس.
- الربط يغطي أوامر المحتوى الـ٢١. أوامر الحالة والتحكم والمساعدة الـ١٥ لا تُعطى مصادر تحريرية.
- التطبيقان يستعملان التنفيذ المشترك في `studio_core.runtime`؛ لا يستورد أحدهما الآخر.
- مصادر النصوص الثابتة تظل ملك تطبيق السناب. الإشارة إليها في سجل مشترك **لا تنقلها إلى الحالات** ولا تثبت وجود معالج لها هناك.
- كود محلّل #٥٢ نُقل إلى النواة، وبقي `snap_bot.style_feed` محوّل توافق لواجهته واختباراته.
- ملف `style_sources.json` القديم يحفظ واجهة الاعتماد القديمة فقط؛ قائمته المفعّلة فارغة، ولا تمنح أي مصادر مرشحة صلاحية تشغيل.

## نتيجة فحص الخلاصات

الفحص التفصيلي موجود في `source-probes-20261030.json`، دون نسخ المقالات أو عناوينها.
استُخدمت استجابة الشبكة العامة في بيئة التطوير، ثم محلّل RSS/Atom المشترك الذي يرفض
HTML وDTD والتواريخ غير الصالحة. المحاولات قد تتبع تحويلات HTTP عبر أداة التطوير؛
وكيل الشبكة الإنتاجي يرفض التحويلات. لذلك لا يثبت هذا الفحص وصول السيرفر أو وكيله.

- الفحص الأول ببنية XML وحدها نجح مع ٢٤ من ٢٥ خلاصة.
- الفحص الأشد بالمحلّل أعطى ٢٣ من ٢٥ نتيجة متحققة وقت التسجيل؛ رابط بازار أريبيا الإنجليزي لم يعط XML قابلًا للتحليل.
- اسم «الحدث – المغرب العربي» تجاوز حد اسم المصدر في المحلّل؛ قُصّر الاسم في السجل إلى «الحدث المغرب العربي». إعادة فحص الشبكة بعد التصحيح انتهت بمهلة؛ لم يُمنح اعتماد تشغيلي.
- خلاصتا أديداس تعملان من بيئة التطوير، خلاف نتيجة ٤٠٣ القديمة. بقيت الترجمة العربية وشبكة الإنتاج غير معتمدتين.
- فُحصت بنية بعض المصادر المستبعدة لتوثيق الحالة فقط؛ نجاح الجلب **لا يلغي استبعاد شروط الاستخدام**.
- محاولة إنشاء وكيل Network Core محلي توقفت عند `PermissionError: [Errno 1] Operation not permitted` لإنشاء مقبس Unix. لم تُغيّر حماية البيئة أو إعدادات السيرفر لتجاوز ذلك.

السجل التاريخي للمسح وشروط الاستخدام محفوظ في `STYLE-SOURCE-SURVEY-20261029.md`؛
نتائج الوصول القديمة فيه تاريخية ولا تستبدل الفحص الأحدث.

## فحص السجل في التطبيقين

```sh
uv run --frozen snap-bot sources --command 'الأناقة'
uv run --frozen status-bot sources --command '٩'
uv run --frozen snap-bot sources
```

هذه أوامر قراءة محلية، لا تتصل بالشبكة ولا ترندر ولا ترسل، وتوضح أن التفعيل والنشر
غير مُمكّنين. أسماء الأوامر وأرقامها تطابق القائمة القائمة؛ لا أوامر جديدة داخل
قائمة تيليجرام أو واتساب.

للفحص الشبكي الاختياري من بيئة تسمح بالمقبس، باستخدام وكيل التطبيق المنفصل والمعد
مسبقًا:

```sh
uv run --frozen snap-bot source-check --command 'التقنية' --network-config /path/to/snap-network.toml
uv run --frozen status-bot source-check --command 'التقنية' --network-config /path/to/status-network.toml
```

يلزم إعداد `Config` صالح ووكيل يعمل مسبقًا. الأداة لا تبدأ خدمة ولا توسع قائمة
المضيفين، وترفض إعداد شبكة التطبيق الآخر. كل مرشح له محاولة واحدة دون إعادة؛
المستبعدات ومواقع الويب غير المثبتة كخلاصات لا تُجلب. الخرج عدد عناوين صالحة وبصمة
استجابة أو نوع فشل منقح، دون نص العناوين أو الروابط السرية. لا تُفعّل الأداة المصدر
بعد نجاحه تلقائيًا ولا تمنحه ترخيص نشر.
إذا فشل مرشح أو لم توجد خلاصة صالحة، تُرجع الأداة حالة فشل بدل إشارة نجاح عامة.

- نجحت فحوص التنسيق والقواعد، وفحص الأنواع الصارم على ١١٨ ملف مصدر.
- فحص GitHub على الرأس الجديد مطلوب قبل أي دمج؛ الاختبارات المحلية لا تثبت التشغيل الإنتاجي.
