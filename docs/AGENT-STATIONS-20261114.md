# الوكلاء الـ١٨ في سبع محطات — ١٤ نوفمبر ٢٠٢٦

سجل واحد في `studio_core/observability/agent_registry.json`، بدل سجل سناب وسجل واتساب وقائمة أدوار اللوحة المنفصلة. تقرؤه النواة والبوتان واللوحة وأدوات الأوامر ومسجل الأحداث في Node. تبقى سلسلة التنفيذ الفعلية وترتيبها وبصمات أدلتها كما هي؛ المحطات تنظيم للأدوار ولا تعني دمج قواعد البيانات أو ترتيب تنفيذ جديد.

| المحطة | الأدوار |
|---|---|
| المصدر | المصدر، المدير |
| الذاكرة | الذاكرة، التناوب، المحلل |
| النص | الكاتب، العربية، التدقيق، الترجمة |
| التصميم | التصميم |
| الصوت والإخراج | الصوت |
| الفحص | الوسائط، الحَكَم، الجودة، المراجع، المصلح، إصلاح المحتوى |
| التسليم | البوابة النهائية |

## صدق الربط

الربط المعلن لا يثبت التشغيل أو اعتماد الوظيفة، ولا يضيف نموذج ذكاء اصطناعي. الأدوار الستة الإشرافية لها فحوص محلية في مسار الإنتاج المشترك. أدوات الأوامر المباشرة الست موجودة في واتساب؛ في سناب ليست مربوطة بأوامر المالك. يظهر «غير مربوط» في تفاصيل أداة سناب وفي ردها، حتى لو نجح فحص الدور داخل إنتاج سابق. لا تُمسح الأدلة التاريخية. الدور بلا ربط لا يُرقّى إلى نجاح بواسطة سجل قديم، وتبقى هويات وسجلات البوتين مستقلة.

## كيف يُتحقق منه على الجهاز

تشغّل شيهانة `scripts/lint.sh` و`scripts/test.sh all` و`node apps/snap-bot/tests/run_agent_runtime.mjs`، ثم تفتح «الوكلاء» في اللوحة: سبع محطات و١٨ صفًا لكل بوت. تختار الكاتب؛ يظهر ربط أمره في واتساب وعدم ربطه في سناب. تطلب «حالة الوكلاء» وقائمة «أدوات الوكلاء» في البوتين. لا يُدّعى نجاح دور بلا رصد. تصنع معاينة بلا إرسال في كل بوت، مع بقاء المدة والنص والمصدر والصوت كما كانت (سناب ≥٦٥ث، واتساب ≤٥٨ث). لا نشر أو جدولة من Codex.

التحقق المحلي: فشل اختبار المحطات السبع وتحذير الأداة غير المربوطة قبل تعديل الواجهة، ثم نجحت اختبارات الواجهة الخمسة. نجحت اختبارات السجل الأربعة ومحاكاة Node الكاملة. فحوص GitHub الكاملة شرط الدمج.
