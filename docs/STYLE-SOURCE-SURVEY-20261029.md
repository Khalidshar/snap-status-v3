### الكود

- style_feed.parse_feed(xml_bytes, source) يعيد title وlink وdate وsource، بترتيب الأحدث أولاً، مع تحويل التاريخ إلى UTC ISO ورفض التاريخ دون منطقة زمنية.
- يقبل RSS 2 وAtom 1، وروابط Atom alternate وحقلي published/updated، وكذلك dc:date في RSS.
- يرفض HTML ومحارف التحكم في الحقول المعادة، بما فيها HTML المشفر وBidi controls والروابط غير الآمنة. لا يعرض descriptions أو صور الخلاصة ولا يحول HTML إلى نص.
- يرفض DTD/entities وXML المشوه والملفات فوق 2 MB وأكثر من ١٠٠٠ عنصر. يرفض العنصر غير الآمن دون تعطيل بقية العناصر الصحيحة.
- يقبل موضوعات الموضة/الجمال/العطور/الماركات بكلمات عربية وإنجليزية أو category أو قسم المصدر المخصص الموثوق. القسم العام brands لا يتجاوز فلتر الكلمات.
- title_fingerprint يستعمل SHA-256 لعنوان NFC مع casefold وطي المسافات. deduplicate يقبل seen من المستدعي لمنع التكرار بين الخلاصات والدورات؛ لا يدّعي تخزيناً دائماً بدون تكامل مستدعي يحفظ seen.
- الملف JSON يحتوي الاسم المختصر ≤٢٠ حرفاً والرابط واللغة؛ المرشحون مفصولون عن sources المعتمدة، ولا يعيدهم sources().
- لا جلب شبكة في الوحدة، ولا تثبيت ترجمة، ولا خدمة مدفوعة.

### اقتراح ترجمة محلية — لا تنفيذ قبل موافقة خالد

Argos Translate خيار مجاني مفتوح المصدر يعمل محلياً على CPU بعد تثبيت الحزمة ونموذج en→ar. [التوثيق الرسمي](https://argos-translate.readthedocs.io/en/stable/) و[فهرس النماذج الرسمي](https://github.com/argosopentech/argospm-index/blob/main/index.json) يعرضان النموذج translate-en_ar-1_0.argosmodel. لم نُنزّل النموذج أو نثبته أو نشغله.

تقدير تخطيطي غير مقاس على السيرفر: نحو ١٠٠–٣٠٠ MB لحزمة نموذج، و٠٫٥–١٫٥ GB مساحة إجمالية للتبعيات والملفات المستخرجة، ونحو ٠٫٥–١٫٥ GB RAM للعناوين القصيرة على CPU. الحجم الفعلي غير مؤكد لأن طلب HEAD إلى مستضيف النموذج أعاد 403؛ لا أقدم هذه الأرقام كقياس أو كمواصفات معلنة للنموذج.

الجودة المتوقعة متوسطة للعناوين العامة، وأضعف لأسماء الماركات والعطور والتلاعب اللفظي والمصطلحات التسويقية. هذا تقدير هندسي، لا نتيجة اختبار. قبل الاعتماد: تجربة عينة صغيرة متوازنة بمراجعة خالد، وتثبيت نسخة النموذج وبصمته وترخيصه، وقاموس أسماء ماركات معتمد، وحفظ الأصل والمصدر، ومنع نشر ترجمة غير مراجعة. وجود إذن لتوزيع RSS لا يُفهم تلقائياً كإذن ترجمة؛ يتحقق ذلك لكل مصدر قبل التشغيل. لا خدمة ترجمة مدفوعة ولا نقل نصوص لخدمة ترجمة خارجية.

### التحقق وحدود النتيجة

٢١ اختباراً ناجحاً باستخدام ملفَي XML اصطناعيين محفوظين في tests/fixtures/style، بلا شبكة. ruff والتنسيق وmypy لحزمة snap_bot (56 ملفاً) ناجحة. تشمل الاختبارات RSS/Atom، الفلتر، التطبيع والبصمة، منع التكرار عبر دورات المستدعي، HTML والتحكم، DTD، الحجم، التواريخ والروابط، واستبعاد المرشحين من القائمة المعتمدة.

فرع مستقل من main عند 8d0bded. لم تتغير fact_layout.py أو render.py أو owner_commands.py، ولا السيرفر أو المفاتيح. لم يتغير سلوك أمر «الأناقة» الحالي: ربطه بأخبار حية يحتاج مصادر تجتاز التحقق والجلب عبر Network Core وتكامل العرض والترجمة بعد اعتمادها. لا ندّعي اكتمال ذلك ضمن هذه المسودة. لا دمج.
