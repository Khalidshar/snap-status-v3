# نافذة واتساب خلال ٢٤ ساعة

النافذة تُقرأ من whatsapp_windows لهوية المالك الموثقة فقط. webhook الموجود يتحقق من توقيع Meta والحساب والهاتف والمالك ويحدّث وقت آخر رسالة ضمن معاملة إدخال الأمر نفسها. لا تعيين نافذة من نص المستخدم أو متغير تشغيل أو وقت استلام طلب غير موثق. الإعادة بنفس الرسالة لا تؤجل انتهاء النافذة لأن التحديث يستخدم وقت الرسالة الأصلي وأكبر وقت موثق.

قبل أي معالجة وإرسال رد نصي يعاد التحقق من أن 0 <= الآن - آخر رسالة < 86400؛ عند الثانية 86400 تُغلق، والوقت المستقبلي أو المفقود أو غير المحدود مرفوض. مسار الفيديو في #67 يعيد التحقق قبل رفع المقطع وبعده، ومسار Outbox القديم يفحص النافذة أيضاً دون تخفيفه.

خارج النافذة لا تُرسل حتى رسالة تفسيرية. يسجل الأمر BLOCKED_OR_UNKNOWN مع السبب الثابت WA_SERVICE_WINDOW_CLOSED ويكتب السبب نفسه فقط في سجل الخدمة. عرض «الحالة» المحلي يبين النافذة ووقت انتهائها بالعربي بنظام ١٢ ساعة؛ إرسال أمر «الحالة» الصحيح من المالك يجدد النافذة ثم يسمح بالرد. اللوحة تقرأ الحالة دون إرسال رسالة.

لا جدولة أو قوالب مدفوعة لفتح النافذة، ولا حذف للسجل أو إعادة تلقائية للأمر الممنوع.
