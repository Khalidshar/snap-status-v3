# إنتاج البوتين القديمين — مرجع حرفي لكل أمر

قرأته شيهانة كاملاً في ٣ نوفمبر ٢٠٢٦ من:
- `Khalidshar/status-bot` عند `b445281` (واتساب): `run.py` و`newsroom.py` و`qa.py` و`agents/*` و`religious_sources.py` و`quran_source.py` و`templates/*` و`worker/worker.js`.
- `Khalidshar/snap-bot` (سناب): `snap.py` و`agents.py` و`qa.py` و`brand.json` و`templates/base.css`.

## المحرك المشترك
- **الرسم:** صفحة HTML عربية RTL بمقاس 1080×1920 يرسمها Chromium (Playwright) إطاراً إطاراً. في الحالات ٣٠ إطاراً/ث، وفي سناب ١٥ إطاراً/ث بطبقة شفافة.
- **التركيب (ffmpeg):** فيديو خلفية من Pexels أو Pixabay، معتّم قليلاً، وفوقه طبقة النص.
- **الخطوط:** المهند (Kufi وCairo)، وأميري للآيات.
- **الهوية:** «👻 خالد» أو handle `khalid-s2ss`، وشريط تقدم أصفر، وبطاقة «تابعني» في سناب.
- **الخلفية حسب النوع:** للأخبار «city night timelapse»، وللفجر «sunrise sky»، وللمطر والليل «rain window night»…
- **فحص الجودة (`qa.py`):**
  - الصوت: بين −18 و−11 LUFS، وذروة −1، ولا صمت طويل.
  - المقاس والإطارات: 1080×1920، و٣٠ إطاراً/ث، وH.264 مع AAC.
  - الحجم: ≤ 16MB لواتساب.
  - الطول: ≤ 60ث.
  - المحتوى: لا نص يطلع برا الإطار، واليوزر ظاهر، وبطاقة «تابعني» موجودة.
  - عند الفشل يصلح ويعيد البناء مرة.
- **المقيّم النهائي:** يقيّم من ١٠ على لوحة من ٦ لقطات. يستخدم Gemini إذا وُجد `AI_TOKEN`، وإلا قائمة تحقق. ملاحظة «خبر بدون صورة» تنقص الدرجة.
- **الذاكرة:** لا تكرار للخبر ٤ أيام في واتساب، ولا تكرار للموضوع في سناب.

## بوت الحالات (واتساب) — `run.py`
| الأمر | الإنتاج |
|---|---|
| موجز الأخبار / الظهر / العالم / السعودية / كرة القدم / الأسواق / عاجل | `build_news`: نشرة من ٢ إلى ٤ أخبار (٣ في العاجل). **كل خبر مشهد:** رقم (١/٣)، و**صورة الخبر** (من الخلاصة أو og:image) عليها «مصدر الصورة»، وعنوان، وفقرة تفصيل حتى ٢٣٠ حرفاً من نص المصدر، وتصنيف النزاع والوقت، و«المصدر». العنوان العام «عاجل • النزاعات» أو «وش صار اليوم؟». الطول = طول الموسيقى (≤ ٥٨ث). **الموسيقى:** True Patriot من مجلد `music`، بضبط مستوى ودخول وخروج تدريجي. **المصادر:** الشرق الأوسط، سكاي نيوز عربية، BBC عربي، فرانس 24، الحدث بنسخه الست. **الترتيب:** السعودية أولاً ثم الترند (Google Trends السعودية). **إذا لم يكفِ عدد الأخبار:** `build_headlines`، أي ٨ عناوين في صفحتين من Google News للعربية والحدث والإخبارية. |
| يومك في دقيقة | `build_brief`: ٤ بطاقات، هي أوقات الصلاة في الرياض، وعدّاد أقرب مناسبة، و«هل تعلم»، و«من تاريخ الإسلام». تحت البطاقات تلاوة بشرية هادئة (~٤٠ث) وطقس متحقق من مصدرين (Open-Meteo وMET Norway)، وخلفية صباحية. |

| آية اليوم / ليلة طيبة / الجمعة / الكهف / الصيام | `build_status`: آيات من مجمع الملك فهد بنصها كما هو، وتلاوة بشرية (قرّاء خاشعون لـ«ليلة طيبة»). تظهر الآيات متزامنة مع التلاوة، ثم تذكير، مع خلفية حسب المشهد. |
| حديث اليوم | `build_hadith`: حديث صحيح من `hadith_verified.json`، ومصدره ودرجته، بقراءة صوتية مولّدة (edge-tts). |
| قبل النوم | `build_night`: سلسلة ليالٍ مرقّمة. آيات بتلاوة خاشعة، ثم حديث مع مطر هادئ مولّد، ثم أذكار نوم بتسجيل بشري مع أعمدة صوتية. |
| الإرسال | رفع الفيديو لواتساب بوصف فيه المصادر والروابط ومصدر الصور ونتيجة الجودة والتقييم. إذا تجاوز ٥٨ث يُقسَّم إلى أجزاء من ٥٥ث. |

| هل تعلم | ٤ معلومات، كل واحدة بطاقة، بعد جملة افتتاحية وقبل «تابعني». |
| لغز اليوم | ٣ ألغاز، لكل لغز عدّاد ٥ ثوانٍ بصوت تك ثم الجواب. |
| مواقف طريفة | ٤ مواقف، لكل موقف جملة ثم النكتة بصوت pop. |
| آية اليوم (تدبّر) / قبل النوم | آيات من مجمع الملك فهد **مع التفسير الميسّر** تحت كل آية (quranenc). التلاوة بشرية من mp3quran أو everyayah. **بدون موسيقى.** |
| أذكار الصباح / المساء | ذكر من حصن المسلم **بتسجيله الصوتي** الرسمي، مع عدد التكرار. |
| حديث اليوم | حديث صحيح بقراءة مولّدة، ومصدره ودرجته. |
| الإرسال | إلى تيليجرام، مع وصف جاهز للنسخ، ووسوم SEO، ومصدر الخلفية والموسيقى، ونتيجة الجودة والتقييم. |

## قواعد عامة من `brand.json`
- لا معلومة خارج المصدر، والحياد، والمناسبة للعائلة.
- **ذكر مصدر الخبر ومصدر الصورة دائماً.**
- الموسيقى مرخّصة فقط، **ولا موسيقى مع القرآن**، وأصوات الأدعية والتلاوة **حقيقية وليست ذكاءً اصطناعياً** (عدا قراءة الحديث في الكود).
